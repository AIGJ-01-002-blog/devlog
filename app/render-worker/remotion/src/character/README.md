# 쇼츠 캐릭터 자리

이 폴더에 Lottie 파일(.json)을 넣으면 고양이 대신 그 캐릭터가 연기해요. 파일 이름은 동작 이름이에요.
규격은 [쇼츠 캐릭터 제작 도면](https://claude.ai/code/artifact/e4a20502-3552-4e83-a3d2-8abeb955c8b0): 512×512, 투명 배경, 30fps, 발끝이 아래 가운데.

| 파일 | 동작 |
|---|---|
| idle.json | 가만히 서서 숨쉬기(없으면 캐릭터를 쓰지 않음) |
| talk.json | 말하기 |
| point.json | 오른쪽 위를 가리키며 설명 |
| happy.json | 두 팔 들고 뛰기 |
| shock.json | 깜짝 놀라기 |
| sad.json | 슬퍼하기 |
| think.json | 생각하기 |
| typing.json | 키보드 치기 |
| idea.json | 아이디어 |
| sleepy.json | 졸기 |
| panic.json | 허둥대기 |
| walk.json | 걷기 |

없는 동작은 idle(말할 때는 talk)로 대신해요. 출처와 라이선스는 이 파일 아래에 적어 주세요.
