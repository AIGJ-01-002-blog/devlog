# Feature Specification: 설정 › AI 연결의 연결 안내

**Feature Branch**: `087-ai-connect-guide`
**Created**: 2026-10-11
**Status**: Implemented (v1.64.0)
**근거**: 블로그 주인이 ChatGPT 개발자 모드로 devlog를 직접 연결해 보면서 메뉴 위치, 서버 URL과 터널의 차이, 동의 화면의 경고, "연결 성공" 뒤에도 [연결]·[허용]이 남아 있는 것, 토큰 연결과 로그인 연결의 차이를 계속 물었다. "우리 메인 기능인데 처음 접하는 사람들에게 친절하게 안내해야 한다"고 요청했다.

## Requirements
- **FR-001**: 설정 › AI 연결 맨 위에 두 연결 방식(로그인 연결: ChatGPT·Claude 앱 / 토큰 연결: Claude Code·Cursor·Codex)을 한눈에 보여 준다.
- **FR-002**: 앱별 연결 순서를 접는 칸(ChatGPT, Claude 앱, Claude Code·Cursor·Codex)으로 나눈다. 로그인 연결 칸에는 서버 주소를 복사 버튼과 함께 둔다.
- **FR-003**: ChatGPT 칸은 지금 메뉴 이름(설정 › 플러그인 › [추가] › 사용자 지정 MCP 서버 추가), 연결은 "서버 URL", 인증은 OAuth, 플러그인 화면의 [연결] → 동의 화면 [허용]까지 적는다. 개발자 모드 위치와 요금제 차이(Plus·Pro 읽기만)를 덧붙인다.
- **FR-004**: 자주 묻는 질문: 동의 화면의 빨간 경고(스스로 등록한 앱 이름), 목록에 안 보일 때(허용 뒤 앱으로 돌아올 때까지 기다리고 다시 [연결]), 두 방식의 차이.
- **FR-005**: 접는 칸마다 무엇을 여는지 툴팁을 단다. 휴대폰에서는 두 방식 카드를 한 줄에 하나씩 놓고 가로로 넘치지 않는다.
- **FR-006**: /mcp 안내의 ChatGPT 문장도 같은 메뉴 이름으로 고친다.

## 고른 기본값 (질문 없이 정함)
- 단계 안내는 처음에 모두 접어 둔다. 이미 연결한 회원에게는 토큰 목록과 설정이 바로 보여야 하고, 처음 온 회원은 쓰는 앱 하나만 펴 보면 된다.
- 새 화면을 만들지 않고 설정 › AI 연결 안에 넣었다. 회원이 연결 목록을 확인하는 곳과 같은 화면이라 "목록에 생기면 끝"을 바로 확인할 수 있다.
- ChatGPT 메뉴 이름은 자주 바뀌므로 "메뉴 이름은 자주 바뀌어요"와 날짜(2026년 10월 기준)를 함께 적었다.
