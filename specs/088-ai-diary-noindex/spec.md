# Feature Specification: AI 일기를 검색 수집에서 빼기

**Feature Branch**: `088-ai-diary-noindex`
**Created**: 2026-10-12
**Status**: Implemented (v1.65.0)
**근거**: spec 085의 남은 질문 "AI 일기를 구글 검색 수집에서 뺄까요?"에 블로그 주인이 2026-10-12 일일 보고에서 "빼기"로 답했다. 애드센스가 "가치가 별로 없는 콘텐츠"로 반려했고, 하루 메모를 묶은 짧은 일기 글이 그 원인 중 하나로 꼽혔다.

## Requirements
- **FR-001**: 자정 AI 일기(071)로 만든 글은 `post.ai_diary = true`로 표시한다. 만들 때 정하고 바꾸지 않는다. 제목을 고쳐 다시 발행해도 표시는 남는다.
- **FR-002**: 표시된 글의 상세 화면은 공개 글이어도 `<meta name="robots" content="noindex">`로 내려 검색 엔진 수집을 거부한다. 수집하지 않는 화면이라 애드센스 광고 코드도 넣지 않는다(076).
- **FR-003**: 사이트맵(`/sitemap.xml`)에 표시된 글을 넣지 않는다.
- **FR-004**: 블로그·홈·태그·피드 목록과 RSS, 글 화면 자체는 지금처럼 독자에게 보인다.
- **FR-005**: 이미 만든 일기는 마이그레이션(V32)에서 자정 작업이 붙이는 제목 형식 `YYYY-MM-DD 개발 일기`로 찾아 표시한다.

## 고른 기본값 (질문 없이 정함)
- RSS에서는 빼지 않았다. 구독자는 일기를 보려고 구독했을 수 있고, RSS는 검색 수집 경로가 아니다.
- 사람이 같은 형식의 제목을 쓴 글도 V32에서 표시될 수 있다. 영향은 검색 수집·광고에서 빠지는 것뿐이라 그대로 두었다.

## 확인
- `AiJournalTest.발행된_일기는_블로그에_보이되_검색_수집_사이트맵_광고에서_빠진다`: 일기를 발행하면 글 화면에 본문과 `noindex`가 있고 광고 코드가 없으며, 사이트맵에 없고, 블로그 목록 API에는 있다.
