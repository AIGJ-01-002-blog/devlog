# Feature Specification: 쇼츠 채널을 블로그에 잇기

**Feature Branch**: `feature/103-shorts-channel-links`, `feature/103-shorts-on-blog`
**Created**: 2026-10-18
**Status**: Implemented
**근거**: 2026-10-18 블로그 주인 질문 "숏츠 스튜디오에서 생성한 숏츠를 올리는 채널을 사용자의 블로그에 연동하고 싶은데 어떻게 하는게 좋을까?"에 대한 추천안. 목표 이슈 #397, 할 일 #398·#399.

## 고른 것과 이유

- **플랫폼 로그인(OAuth)·자동 업로드는 하지 않는다**: 2026-10-14 "자동 올리기 말고 수동으로" 결정(099)을 지킨다. YouTube·TikTok은 심사(audit)를 통과하기 전 API로 올린 영상을 비공개로 잠그고, Instagram은 권한마다 App Review가 필요하다(2026-10 각 개발자 문서). 회원마다 플랫폼 토큰을 보관할 부담도 없다.
- **채널은 소셜 정보(043)의 칸으로 둔다**: 이미 블로그 머리·글 작성자 영역·설정 화면이 같은 칸 묶음을 그리므로, 새 테이블 없이 종류만 더한다.
- **YouTube는 youtube.com/ 뒤 경로로 저장한다**: 핸들(@이름, 여러 언어 글자)과 채널 ID(UC…)를 함께 받으려면 둘을 구분해야 해서 `@핸들` 또는 `channel/UC…`로 둔다.
- **블로그에 보이는 쇼츠는 회원이 직접 남긴 영상 주소로만 만든다**: devlog가 플랫폼에 나가 영상이 있는지 확인하지 않는다(099 FR-015와 같다).

## 요구 사항

### 1단계: 채널 칸 (#398)

- **FR-001**: 소셜 정보 종류에 YOUTUBE·INSTAGRAM·TIKTOK을 더한다(V56, `member_social_link` CHECK 제약).
- **FR-002**: YouTube는 `youtube.com/@핸들[/…]`, `youtube.com/channel/UC…`(22자), `@핸들`, 핸들, 채널 ID를 받는다. 핸들은 글자·숫자·밑줄·하이픈·마침표 3~30자, 주소의 퍼센트 인코딩은 풀어서 저장한다. 영상 주소(watch, youtu.be)는 받지 않는다.
- **FR-003**: Instagram은 영문·숫자·밑줄·마침표 1~30자, TikTok은 2~24자 아이디를 받는다. 프로필 주소를 붙여 넣으면 아이디를 꺼내고, 게시물·영상 주소는 받지 않는다.
- **FR-004**: 블로그 머리·글 작성자 영역 링크는 GitHub 뒤 순서(이메일·GitHub·X·Facebook·홈페이지·YouTube·Instagram·TikTok)로 보이고, 마우스를 올리면 "YouTube 채널 @핸들"처럼 툴팁이 뜬다.
- **FR-005**: 스튜디오 올리기 안내에서 고른 플랫폼의 채널을 넣었으면 [내 채널 열기](새 탭), 없으면 "설정에서 채널 넣기" 안내를 보인다.

### 2단계: 블로그·글 화면의 쇼츠 (#399)

- **FR-006**: `shorts.on_blog`(V57, 기본 true)로 회원이 쇼츠마다 블로그·글 화면에 보일지 고른다. `PUT /api/me/shorts/{id}/blog {visible}`. 대본 버전은 올리지 않는다. 스튜디오 올리기 안내에서 남긴 주소가 하나라도 있으면 [내 블로그 [쇼츠] 탭과 바탕 글 아래에 보이기] 체크가 보인다.
- **FR-007**: `GET /api/members/{handle}/shorts`(최근 올린 순 60편)·`GET /api/posts/{id}/shorts`(6편)는 누구나 읽는다. 남긴 주소가 하나 이상이고 `on_blog`이며 회원이 탈퇴하지 않았고, 바탕 글이 있으면 그 글이 공개·발행·숨김 아님일 때만 보인다. 바탕 글이 없는 쇼츠(매매 재현 등)는 블로그 탭에만 보인다. 쇼츠가 꺼진 서버는 404다.
- **FR-008**: 카드에는 제목·길이·바탕 글 링크·플랫폼별 링크(새 탭, nofollow)를 둔다. YouTube 주소(shorts·watch·youtu.be·embed·live)에서 영상 ID를 꺼내면 썸네일(i.ytimg.com)을 보이고, 누르면 그 자리에서 `youtube-nocookie.com` 임베드로 재생한다. 썸네일을 못 받거나 YouTube가 아니면 제목을 얹은 색 카드로 그 플랫폼에 간다. Instagram·TikTok 임베드 스크립트는 싣지 않는다.
- **FR-009**: 블로그 [쇼츠] 탭(`/@handle/shorts`)은 쇼츠가 켜진 서버에서 주인에게는 늘, 남에게는 보일 쇼츠가 있을 때만 메뉴에 보인다. 서버가 첫 화면(제목·영상 링크 목록)을 그리고, 수집하지 않는다(noindex). 글 상세는 공개 발행 글에서만 "이 글의 쇼츠"를 받는다. 휴대폰은 두 줄 카드다.

## 범위 밖

- 채널 최신 영상 자동 가져오기(YouTube 채널 RSS). devlog에서 만들지 않은 영상까지 보이고 싶을 때 다음 목표로.
- 채널 소유 확인 배지(OAuth 읽기 전용).
