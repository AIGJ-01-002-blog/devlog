**Feature Branch**: `102-server-paper-bot` (작업 브랜치 `feature/trade-bot-coin-candles-ca44fu`)
**Created**: 2026-10-15
**Status**: 1단계 Implemented (켜기·끄기, 서버 모의 봇, 안내 문구). FR-004 대화 기준 도구는 다음 단계
**결정**: 2026-10-15 블로그 주인이 "서버 자동"을 골랐다(각자 설치 대신)
**근거**: 2026-10-15 블로그 주인 "다른 사람들도 그냥 자동으로 봇이 연결되는줄 알았는데"

## 고른 것과 이유

- **모의만 서버가 돌린다**: 모의 매매는 거래소 키 없이 공개 캔들만 쓰므로 서버가 회원마다 돌려도 키를 맡지 않는다. 실거래는 지금처럼 블로그 주인 맥에서만 돈다(2026-10-15 17:38 결정). 다른 사람 키를 서버에 두거나 자동 카피 트레이딩은 하지 않는다.
- **켜는 사람만 돈다**: /trade 빈 화면에 [모의 봇 켜기] 버튼을 둔다. 가입만으로 모두 돌리지 않는 이유는 서버 부담과, 원하지 않는 사람에게 매매 기록이 쌓이지 않게 하려는 것이다.
- **봇 코드와 같은 규칙**: trade-bot의 이동평균 교차(봉 수·손절·익절·하루 수익 멈춤)를 그대로 옮긴다. 처음 현금은 바이낸스 1,000 USDT·업비트 1,000,000원(봇 기본값과 같다). 포인트가 켜진 서버에서는 두 계좌 모두 회원의 기본 크레딧으로 사고판다(#331, #339: 1크레딧 = 1원, 바이낸스 계좌는 신호만 USDT 봉에서 받고 체결은 원화 시세).
- **사람이 늘어도 느려지지 않게**: 거래소 호출은 회원 수와 상관없이 5분에 (거래소 2 × 코인 5)번이고, 회원마다는 60봉 평균 계산과 DB 몇 줄뿐이다. Gemini는 부르지 않는다. 예약 작업은 JobLock으로 서버 한 대에서만 돈다.
- **결과는 spec 101 표에 그대로 쓴다**: `trade_bot_account`·`trade_bot_event`에 계좌 `server-paper-<거래소>-spot-1h`로 남겨 화면·차트 표시를 고치지 않는다. 회원이 자기 맥 봇도 함께 돌리면 계좌 이름이 달라 섞이지 않는다.
- **시세는 TradeCharts 캐시를 함께 쓴다**: (거래소, 봉)마다 한 번만 받아 모든 회원이 나눠 쓴다. 회원 수가 늘어도 거래소 호출은 늘지 않는다.
- **기준은 내 AI가 바꾼다**: devlog MCP에 `trade_bot_rules`와 같은 모양의 도구를 두어 코인·봉 수·손절·익절·멈춤을 바꾼다. 상한은 trade-bot과 같다.

## 사용자 시나리오

1. **Given** 로그인한 회원이 /trade를 처음 연다, **When** [모의 봇 켜기]를 누르면, **Then** 다음 5분 바퀴부터 바이낸스·업비트 모의 계좌가 생기고 체결이 쌓인다.
2. **Given** 켜 둔 회원, **When** [끄기]를 누르면, **Then** 다음 바퀴부터 돌지 않고 기록은 남는다.
3. **Given** 회원의 AI가 MCP로 손절을 2%로 바꾼다, **Then** 다음 바퀴부터 그 값으로 돌고 계좌 규칙에 "기준을 정한 곳: 대화(AI)"가 보인다.
4. **Given** 거래소 시세를 받지 못했다, **Then** 그 바퀴는 건너뛰고 다음 바퀴에 다시 한다. 같은 봉을 두 번 거래하지 않는다.

## Requirements

- **FR-001**: 새 표 `trade_paper_bot`(회원, 켜짐, 규칙 JSON, 종목별 마지막 처리 봉, 하루 수익 JSON). 탈퇴 정리 때 지운다.
- **FR-002**: `@Scheduled` 5분 작업이 켜진 회원마다 1시간봉 닫힌 봉으로 판단하고 `trade_bot_account`·`trade_bot_event`(FILL)에 남긴다. 회원 하나가 실패해도 나머지는 돈다.
- **FR-003**: `PUT /api/me/trade-bot/paper` `{enabled}`로 켜기·끄기(`GET`은 지금 상태). `TRADES_ENABLED`가 꺼져 있으면 404.
- **FR-004 (다음 단계)**: MCP 도구 `paper_bot_rules`(get·set·clear). 상한: 코인 10개, 2~60봉, 손절 0.5~20%, 익절 0(끔)·0.5~50%, 하루 수익 멈춤 0·0.5~20%, 한 번 금액은 기본값 이하.
- **FR-005**: /trade 안내: 봇은 규칙으로 도는 자동 프로그램이고, AI는 기준을 정하거나(MCP) 진입을 거르는(Gemini) 데만 쓴다는 것, 모의만 보인다는 것, 투자 권유가 아니라는 것을 화면에 적는다.
