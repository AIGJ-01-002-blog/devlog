# Feature Specification: 아무것도 쓰지 않은 임시글은 나갈 때 바로 지우기

**Feature Branch**: `091-discard-empty-draft`
**Created**: 2026-10-12
**Status**: Implemented (v1.66.2)
**근거**: 민서님 요청(2026-10-12) "사용자가 아무 내용없이 실수로 글쓰기 눌렀다가 바로 나왔을때 임시글로 남는 현상이있는데 이런경우 휴지통으로 가지말고 바로 삭제 해줘".

## 원인
[글쓰기]는 임시글을 먼저 만들고 에디터를 연다(002). 아무것도 쓰지 않고 나오면 그 글이 임시글 목록에 남았다. 새벽 정리(EmptyDraftCleanupJob)는 만든 지·고친 지 24시간이 지난 빈 글만 지우는데, [글쓰기]를 다시 누르면 같은 빈 글을 이어 쓰며 수정 시각이 바뀌어 계속 남아 보였다.

## Requirements
- **FR-001**: 에디터에서 나갈 때([← 나가기], 브라우저 뒤로 가기, 다른 화면으로 이동) 아무것도 쓰지 않은 임시글이면 휴지통을 거치지 않고 바로 완전 삭제한다. 이 기기에 남은 작성 데이터도 지운다.
- **FR-002**: "아무것도 쓰지 않은 임시글"은 상태가 임시글이고 제목·본문이 공백뿐이며, 짧은 소개·태그·사진·첨부파일·썸네일·시리즈가 모두 없는 글이다(`PostSql.BLANK_DRAFT`). 한 글자라도 있으면 지금처럼 임시글로 남긴다.
- **FR-003**: 서버가 최종 판단한다(`DELETE /api/posts/{id}/if-empty` → `{deleted}`). 서버에 잠시 보관 중인 자동 저장분을 먼저 반영하고 다시 확인하며, 자동 저장분을 확인할 수 없으면 지우지 않는다. 발행한 글·휴지통의 글·남의 글은 지우지 않는다(남의 글·없는 글은 404).
- **FR-004**: 같은 기준을 [삭제] 바로 삭제(007 FR-002), 새벽 빈 임시글 정리(002 FR-016), [새 글]의 빈 임시글 이어 쓰기에도 쓴다. AI(MCP)로 만든 임시글과 `delete_post`도 같은 기준을 따른다.

## 고른 기본값 (질문 없이 정함)
- 탭을 닫거나 새로 고침할 때는 지우지 않는다. 새로 고침에서 지우면 다시 열린 에디터가 "없는 글"이 되기 때문이다. 이렇게 남은 빈 글은 [글쓰기]를 다시 누르면 이어 쓰이고, 쓰지 않으면 새벽 정리가 지운다.
- 별도 안내 문구는 띄우지 않는다. [← 나가기] 툴팁에 "아무것도 쓰지 않은 글은 남기지 않아요"를 더했다.
- 예전에는 제목·본문만 비면 [삭제] 시 바로 지웠지만, 이제 태그·사진 등이 있으면 휴지통으로 간다(되살릴 수 있는 쪽이 안전).
