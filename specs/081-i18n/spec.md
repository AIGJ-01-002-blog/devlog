# Feature Specification: 화면 다국어 (영어·일본어·중국어) 1단계

**Feature Branch**: `081-i18n`
**Created**: 2026-10-10
**Status**: Implemented (1단계: 읽기·로그인·가입 화면, 2단계: 글쓰기·설정·관리·안내 화면)
**근거**: 2026-10-10 블로그 주인 질문 "블로그 영어, 일본어, 중국어 언어 지원도 하게 해서 글로벌하게 하고 싶어"와 결정 카드의 [페이스북+다국어] 선택. 순서는 다국어 기반 → 영어 → 일본어·중국어, 그다음 페이스북 로그인이다.

## 사용자 시나리오

1. **Given** 브라우저 언어가 영어·일본어·중국어인 방문자, **When** devlog를 처음 열면, **Then** 머리말·아래 탭·첫 화면·글·블로그·검색·태그·시리즈·로그인·가입·알림 화면이 그 언어로 보인다. 그 밖의 언어는 한국어다.
2. **Given** 어느 화면이든, **When** 머리말 테마 버튼 옆 🌐 메뉴에서 언어를 고르면, **Then** 페이지를 다시 불러와 그 언어로 보이고, 이 브라우저는 다음 방문에도 그 언어를 쓴다.
3. **Given** 주소에 `?lang=en`(ko·en·ja·zh)이 붙은 링크, **Then** 저장한 언어보다 주소의 언어가 먼저다. 🌐 메뉴로 다시 고르면 주소의 `lang`을 지운다.
4. **Given** 번역하지 않는 곳(관리자 화면, 약관·처리방침 본문)이나 서버가 보낸 오류 문장, **Then** 한국어로 보인다. 화면이 비지 않는다. 약관·처리방침은 제목·시행일·링크만 화면 언어로 보이고, 본문이 한국어 원문뿐이라는 안내가 붙는다(v1.64.2).
5. 글 본문·제목·태그·닉네임은 쓴 사람이 쓴 그대로 보인다(번역하지 않는다).

## Requirements

- **FR-001**: 문장 사전은 한국어 문장을 키로 쓴다(`t('글 {0}편', { 0: n })`). `app/frontend/src/lib/locales/{en,ja,zh}.ts`에 언어별 사전을 둔다. 사전에 없는 문장은 한국어로 보인다.
- **FR-002**: 언어 고르는 순서는 `?lang=` → `localStorage['devlog.lang']` → `navigator.languages` → 한국어. `<html lang>`을 고른 언어로 바꾼다.
- **FR-003**: 언어를 바꾸면 페이지를 다시 불러온다. 메뉴·사유 목록처럼 불러올 때 한 번 만드는 문장도 함께 바뀐다.
- **FR-004**: 큰 수는 언어별 줄임 표기(한국어 1.2만, 영어 12.9K, 일본어·중국어 1.2万). 상대 시간·월일도 언어별 문장이다.
- **FR-005**: 테스트가 화면 코드의 `t('…')` 문장을 모두 모아 세 사전에 빠짐없이 있고 `{0}` 자리가 같은지 확인한다. 새 문장을 더하면 세 사전에도 더해야 CI가 통과한다.

## 고른 것과 이유 (질문 없이 진행, 일일 보고에 기록)

- **라이브러리 없이 작은 `t()`**: react-i18next 같은 라이브러리는 키 이름 짓기와 설정이 늘어난다. 화면 문장이 이미 한국어로 다듬어져 있어 문장 자체를 키로 쓰면 코드가 그대로 읽히고, 번역이 빠져도 한국어로 보인다.
- **언어 메뉴는 머리말 🌐 (v1.59.1)**: 처음엔 맨 아래에 두었다가 블로그 주인 요청으로 테마 버튼 옆으로 옮겼다. 아이콘만 두어 휴대폰 머리말에서도 자리를 적게 쓴다.
- **바꾸면 새로 불러오기**: 모든 문장을 화면이 그릴 때마다 번역하게 바꾸는 것보다 단순하고, 언어는 거의 바꾸지 않는다.
- **주소는 그대로(`/en/...` 경로 없음)**: 경로를 언어별로 나누면 검색 노출에는 좋지만 서버 렌더링·사이트맵·canonical을 모두 바꿔야 한다. 글 본문이 한국어인 지금은 화면 문장 번역이 먼저다. 언어별 경로는 글 번역이 생길 때 다시 본다.
- **1단계 범위**: 독자가 처음 보는 화면(읽기·로그인·가입·알림)부터. 글쓰기·설정·관리자·약관·서버 오류 문장은 다음 단계에서 같은 방식으로 옮긴다. 약관·처리방침은 법적 문서라 번역본을 따로 검토해야 한다.
