# Feature Specification: 글 읽기 경험 다듬기

**Feature Branch**: `097-reading-polish` (작업 브랜치 `claude/project-thread-dkkmfw`)
**Created**: 2026-10-14
**Status**: Implemented
**근거**: 2026-10-14 블로그 주인 질문 "더 추가하거나 보완해야 할 기능(UI/UX, 버그)"에 운영 v1.68.0을 PC·휴대폰·라이트·다크로 점검한 결과를 올렸고, "지금 모두 반영해주고 수정해줘"라는 답을 받았다. velog에 있고 devlog에 없던 읽기 기능과 점검에서 나온 버그를 한 목표로 묶었다.

## 사용자 시나리오

1. **Given** 잘못된 링크로 들어온 방문자, **When** 없는 주소(예: `/this-does-not-exist`)를 열면, **Then** JSON 글자 대신 머리말과 [홈으로]가 있는 "볼 수 없는 페이지예요" 화면을 본다. 휴대폰에서 가로로 넘치지 않는다.
2. **Given** `**"이 일을 해도 되나?"**를`처럼 따옴표·괄호로 끝나는 굵은 글에 조사가 붙은 본문, **Then** 별표 없이 굵게 보인다.
3. **Given** 코드가 있는 글, **When** 코드 블록 오른쪽 위 [복사]를 누르면, **Then** 코드가 클립보드에 들어가고 "복사했어요"가 잠깐 보인다. [줄바꿈]을 누르면 긴 줄이 화면 폭에 맞춰 접힌다.
4. **Given** 휴대폰으로 긴 글을 읽는 사람, **Then** 본문 위에 접힌 [목차]가 있고 지금 읽는 제목이 함께 보인다. 펼쳐서 제목을 누르면 그곳으로 가고 목차가 닫힌다.
5. **Given** 사진이 있는 글, **When** 사진을 누르면(키보드는 Enter), **Then** 화면 가득 크게 보이고 Esc·[닫기]·바깥 누르기로 돌아온다.
6. **Given** 화면 한 장 반 넘게 내려간 사람, **Then** 오른쪽 아래에 [맨 위로]가 보인다. 휴대폰은 아래 탭 위에 있다.
7. **Given** 남의 글을 읽은 사람, **When** 읽기 목록의 [최근 읽은 글](/lists/read)을 열면, **Then** 이 기기에서 연 글이 최근 순으로 50편까지 보인다. 하나씩 또는 모두 지울 수 있다. 로그인하지 않아도 쓴다.
8. **Given** 검색창만 연 사람, **Then** 이 기기의 최근 검색어 8개와 많이 쓰인 태그 12개가 보여 바로 고른다.
9. **Given** 영어 화면, **Then** 시리즈 날짜 옆은 "Edit"이 아니라 "updated …"이고, 404 화면의 탭 제목도 영어다.
10. **Given** 글 링크를 X·슬랙에 붙인 사람, **Then** 큰 미리보기 카드가 뜨고, 검색 엔진은 글쓴이·날짜가 든 구조화 데이터(BlogPosting)를 읽는다.

## Requirements

- **FR-001**: 어느 주소에도 맞지 않는 요청(NoResourceFoundException)은 GET·HEAD이고 `/api` 밖이며 Accept에 `text/html`이 있으면 앱 404 화면(404, noindex, 저장 안 함)을 낸다. 그 밖(API·파일 요청)은 전처럼 JSON 404다.
- **FR-002**: 본문 렌더러가 파싱 뒤 같은 부모 안에 글자로 남은 `**` 두 개를 굵게 묶는다. 여는 `**`의 앞이나 닫는 `**`의 뒤가 한글·한자·가나일 때만, 안쪽 끝이 공백이 아닐 때만 고친다. 코드 안은 건드리지 않는다. 렌더링 규칙 버전을 4로 올려 기존 글도 새로 그린다(캐시 키가 바뀜).
- **FR-003**: 공개 글 화면 머리말에 `twitter:card`(사진이 있으면 `summary_large_image`)와 JSON-LD `BlogPosting`(headline·description·url·image·datePublished·dateModified·author)을 넣는다. 수집하는 화면에만 넣고, `<`·`>`·`&`는 유니코드 이스케이프로 바꾼다.
- **FR-004**: 글 본문의 코드 블록(그림 블록 제외)에 언어 이름, [줄바꿈](aria-pressed), [복사] 버튼을 붙인다. 클립보드를 못 쓰면 코드를 골라 두고 Ctrl+C를 안내한다. 휴대폰은 아이콘만 보이고 이름은 툴팁과 화면 읽기 프로그램으로 알린다.
- **FR-005**: 1280px 미만에서는 본문 위에 `<details>` 목차를 둔다. 1280px 이상은 전처럼 오른쪽 목차만.
- **FR-006**: 할 일 목록 체크 상자에 "완료: …"/"할 일: …" 이름을 붙인다.
- **FR-007**: 링크 밖의 본문 사진은 누르면 크게 본다(돋보기 커서, 툴팁 "사진 크게 보기", 키보드 초점). 링크 안 사진(GIF 재생·외부 링크)은 링크 동작 그대로.
- **FR-008**: 최근 읽은 글은 브라우저 저장소(`devlog:recent-reads`)에만 50편까지 남긴다. 남의 공개 발행 글만 넣는다. `/lists/read`는 로그인 없이 열고, 회원은 [좋아한 글]과 탭으로 오간다. 맨 아래 링크에 [최근 읽은 글]을 더한다.
- **FR-009**: 검색어 없는 검색 화면에 최근 검색어(브라우저 저장소 8개, 지우기 버튼)와 많이 쓰인 태그를 보인다. 검색 기록은 서버에 저장하지 않는다(014 FR-022 그대로).
- **FR-010**: 화면 높이의 1.5배 넘게 내려가면 [맨 위로]를 보인다. 글쓰기·관리자 화면에는 없다. 움직임 줄이기를 켜면 바로 올라간다.
- **FR-011**: 휴대폰(굵은 포인터)에서 카드 태그·글쓴이 링크·시리즈 배지·로그인 화면 보조 링크의 누르는 자리를 32px 이상으로 넓힌다. 글자 모양은 그대로 둔다.
- **FR-012**: 머리말 테마 버튼에 툴팁을 달고, 테마(모니터·해·달)와 언어(지구) 아이콘을 이모지에서 다른 머리말 아이콘과 같은 선 아이콘으로 바꾼다.

## 고른 것과 이유 (질문 없이 진행, 일일 보고에 기록)

- **최근 읽은 글은 기기에만**: velog는 서버에 읽은 기록을 남기지만, 우리는 서버 테이블·개인정보 처리방침 변경 없이 바로 낼 수 있는 브라우저 저장소를 골랐다. 시리즈 "읽음" 표시(072)도 같은 방식이다. 기기를 넘나드는 기록이 필요하면 다음 목표에서 서버 저장으로 옮긴다.
- **굵게 고치기는 CJK 옆에서만**: CommonMark 규칙을 통째로 바꾸면 영어 글의 결과가 달라진다. 한국어 글에서 생기는 경우만 고친다.
- **점검에서 나왔지만 하지 않은 것**:
  - 글 안 시리즈 목록: 이미 본문 아래 시리즈 상자(072 BranchBox)에 "N편 중 M편"·이전/다음이 있어 그대로 둔다.
  - 휴대폰 공유 창: 이미 손가락 기기에서는 기기 공유 창을 연다(039). 카카오톡 공유는 카카오 JavaScript 키와 도메인 등록이 필요해 일일 보고 질문으로 올린다.
  - 카드 썸네일 링크 이름: 같은 글로 가는 제목 링크가 있어 썸네일은 일부러 화면 읽기 프로그램과 Tab에서 뺐다(aria-hidden, tabindex -1). 점검 도구의 오탐이다.
  - /search·/login 설명 메타: 수집 거부(noindex) 화면이라 효과가 없다.
  - 앱처럼 설치(PWA): 학교 서버 캐시·갱신 문제를 따로 살펴야 해서 미룬다.
  - 광고 스크립트는 이미 `async`로 불러와 화면 그리기를 막지 않는다. 점검에서 첫 화면이 느렸던 것은 점검 환경이 광고 주소를 막아 기다린 탓이다.
