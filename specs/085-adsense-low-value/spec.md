# Feature Specification: 애드센스 "가치가 별로 없는 콘텐츠" 반려 대응

**Feature Branch**: `085-adsense-low-value`
**Created**: 2026-10-11
**Status**: Implemented (v1.62.0)
**근거**: 2026-10-11 애드센스 검토 결과 devlog.life가 "주의 필요 · 가치가 별로 없는 콘텐츠"로 반려됐다(ads.txt는 승인됨). 블로그 주인 요청("왜 반려되었는지 알아내고 해결해줄 수 있어?").

## 점검 결과 (2026-10-11, 스크립트를 돌리지 않는 읽기 도구로 확인)
- 사이트맵의 공개 글 30편 중 17편이 본문 글자 수 1,000자 미만이다(포트폴리오 비유 글 13편, 짧은 소개 글, AI 일기 2편). 그림 위주라 글이 적다.
- `/privacy`·`/terms`는 서버가 빈 껍데기에 `noindex`를 붙여 내려서, 스크립트를 돌리지 않는 검토 도구에는 처리방침이 비어 보였다.
- 글이 하나뿐인 태그 화면 20여 개가 그 글의 카드만 담은 채 검색 수집 대상이었다.
- 사이트 소개(/about, spec 077)와 문의 화면은 이미 있다.

## Requirements
- **FR-001**: 이용약관·개인정보 처리방침 문안은 `policy/terms.html`·`policy/privacy.html` 한 곳에 둔다. 서버가 `/terms`·`/privacy` 첫 화면에 제목·시행일·본문을 그리고 검색 수집을 허용한다(정규 주소·설명 포함). 사이트맵에도 넣는다.
- **FR-002**: React 화면은 첫 화면 데이터(`page: policy`)나 `GET /api/site/policies/{terms|privacy}`로 같은 HTML을 받아 그린다. 다른 값이면 404. 받은 뒤 `#ads` 같은 항목 주소로 내려간다.
- **FR-003**: 공개 글이 2편 미만인 태그 화면은 `noindex`로 내려 검색 수집과 광고에서 뺀다. 2편부터 다시 연다.
- **FR-004**: 약관·처리방침의 로그인 수단에 카카오·Facebook을 더한다(spec 080·083 반영).

## 고른 기본값 (질문 없이 정함)
- 짧은 글을 숨기거나 지우지 않았다. 글은 블로그 주인의 것이라 늘리거나 합치는 판단은 주인이 한다. 대신 보강할 글 목록을 일일 보고에 올렸다.
- AI 일기 글을 noindex로 돌리지 않았다. 주인이 공개를 고른 기능이라 질문으로 올렸다.
